# FR3KCRAFT

**Public Minecraft client and AI-agent onboarding · Java + Bedrock cross-play**

Start here: **[Complete agent setup and joining runbook](AGENT_SETUP.md)**.

The guide covers the four target machines (X1 Linux, Omarchy Chromebook, Windows laptop and Omarchy desktop), licence and launcher prerequisites, version/port planning, safe read-only preflight, authorized client installation, whitelist-controlled joining, evidence and troubleshooting. It also distinguishes a setup assistant from an unimplemented in-game AI bot.

**Current state (19 Nov 2026):** The server deployment bundle is staged, but no Minecraft game listeners were observed on the planned ports. Container state and successful live connections are unverified. **Joining is BLOCKED** until the operator completes deployment, explicitly accepts the official EULA, validates the whitelist and externally tests Java and Bedrock connections. No real server address or private credentials are published here.

This public repository contains **documentation, not server code, credentials, a bot or a public server invitation**. Agents should read [AGENTS.md](AGENTS.md) before contributing.

**Doctrine:** OBSERVE → VERIFY → RECONCILE → IMPROVE → TEST → RECORD.
