# FR3KCRAFT instructions for AI agents and human contributors

**Read [AGENT_SETUP.md](AGENT_SETUP.md) first.** It is the public source of truth for client setup, prerequisites, version reconciliation, join gates and sanitized evidence reporting. This repository is documentation-only; do not fabricate runnable bots, deployed services, access tokens or private repository paths.

- Default to OBSERVE. Install software, authenticate, join servers or mutate worlds only with the operator's explicit, scoped authorization.
- **No verified live game server or join has been established.** Confirm current status before advising any join attempt.
- Preserve raw evidence privately and report CLAIM/OBSERVATION/EVIDENCE/VERIFIED FACT/HYPOTHESIS/SIMULATION/UNKNOWN/BLOCKED appropriately.
- Never publish credentials, player names, private server addresses, local device IDs, world files, backups, key material or session cookies.
- Do not bypass Minecraft licences, account authentication, Floodgate whitelist, EULA acceptance, SSH host verification or RCON isolation.
- When updating version guidance, cite the upstream release/source and distinguish planned versions from observed and tested versions.
- A commit is not deployment, a green CLI exit is not a playable client, and offline Joy/Freik simulations are not in-game NPCs.
- For contributions, change documentation in a PR with a reproducible, sanitized verification plan and an accurate remaining-unknowns section.
